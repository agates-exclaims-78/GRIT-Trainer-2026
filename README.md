## 🔥 Project Overview

**This tool** is a comprehensive trainer for **GRIT**. This trainer provides optional quality-of-life and practice features for GRIT, including player survivability, ammunition management, movement tuning, horse support, and inventory assistance. It is intended for controlled testing and private sessions, not competitive online play.

**Target Audience:** Players testing GRIT mechanics, practicing mounted combat and projectile aiming, experimenting with weapon-suit combinations, or creating private gameplay demonstrations.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

GRIT combines third-person movement with horseback travel. Horses have multiple speeds, can be used to escape the Calamity, and allow players to fire while riding. Use the movement option for controlled traversal tests, and enable Horse Stamina when practicing long-distance rides or mounted engagements.

### Tools & Inventory

Each match uses four weapon slots. Weapons have ranks and suits, and collecting two weapons of the same suit activates a perk while a full matching hand provides the strongest specialization. The trainer's inventory assistance is intended for testing weapon combinations without changing the game's basic four-slot structure.

### World & Environment

The Calamity gradually consumes the map and forces players toward safer areas. Trains move through the battlefield and can provide transport, loot, and a position inside the active zone. Use Calamity Protection only for private exploration or testing, since normal matches require positioning and rotation decisions.

### Combat & Weapons

GRIT uses projectile-based weapons rather than hitscan firearms. Players must lead moving targets and account for bullet drop. Combat can take place on foot or from horseback, and eliminated players may enter a Second Chance one-on-one quick-draw showdown to return to the match. Unlimited Ammo and No Reload are best suited to aim practice and weapon testing.
